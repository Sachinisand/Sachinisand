### How I build pipelines

- **Data quality first.** Validate at the edges, count what is removed and why, and stop bad data before it reaches a report.
- **Reproducible.** Each project runs with one command, and every number in a README comes from a saved result.
- **Tested and automated.** Tests and quality gates run in GitHub Actions on every push.
- **Documented.** Clear READMEs, design decisions and honest limits.
