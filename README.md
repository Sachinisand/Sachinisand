### How I work

- **Data quality first.** I count what I remove and why, for example the 4,032 sales that were reversed by matching cancellations in the e-commerce data.
- **Test on data the work was not tuned on.** In the LLMOps project, a held-out set showed the rule-based extractor dropping from 93 % to 69 %, which changed the conclusion.
- **Reproducible.** Projects run with one command, and every number in a README comes from a saved result file.
- **Honest limits.** Each project states what the data cannot answer (synthetic data, one season, small test sets).
